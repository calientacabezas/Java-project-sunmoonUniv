# 정확도 비교 실험: 규칙만 vs 하이브리드

## 1. 질문

LLM 추출과 의미 재정렬을 붙이면, 사람이 실제로 쓰는 표현(동의어·오타·외국어)에서 주인 물건을 더 잘 찾는가?

## 2. 비교 대상

| 방식 | 처리 과정 |
|---|---|
| 규칙만 (기준선) | `KeywordQueryParser`(enum 표준 이름 일치만, 동의어 사전 없음) → 규칙 점수 → 정렬 |
| 하이브리드 | `PiiMasker` → `LlmQueryParser` → 규칙 점수 → 상위 10개 `SemanticReRanker` |

두 방식은 **같은 습득물 데이터와 같은 검색어 30개**를 사용합니다. 기준선도 자유 입력 문장을 받아야 공정한 비교가 됩니다.

## 3. 데이터 (작성: 권도영)

- 습득물: `data/sample/found_items.txt` 30건 이상. 비슷한 물건(흰 이어폰 여러 개 등)을 섞어 변별력을 확보합니다.
- 평가 케이스: `data/eval/eval_cases.txt` 30건, 각 케이스에 정답 습득물 ID.

| 유형 | 건수 | 예시 |
|---|---|---|
| NORMAL 표준 표현 | 10 | "공학관 3층 흰색 무선 이어폰" |
| SYNONYM 동의어·유사 색상 | 10 | "공대 하얀 버즈", "연분홍 지갑" |
| TYPO 오타 | 5 | "흰샥 무선이어펀" |
| FOREIGN 외국어 | 5 | "white wireless earbuds, engineering building" |

정답을 미리 정한 뒤 실험합니다. 결과를 본 뒤 케이스를 바꾸지 않습니다.

## 4. 지표

- **주 지표: 상위 3개 포함률(Top-3)** = 정답이 상위 3개 안에 든 케이스 수 ÷ 30
- 보조 지표: 1위 적중률(Top-1), 평균 역순위(MRR)
- 유형별(NORMAL/SYNONYM/TYPO/FOREIGN)로 나눠서도 계산합니다.

## 7. 해석할 때 주의

- NORMAL에서는 차이가 작고 SYNONYM·FOREIGN에서 커지는 것이 예상 결과입니다. 그렇지 않으면 원인을 적습니다.
- 하이브리드가 오히려 틀린 케이스는 빼지 말고 사례로 분석합니다. 발표에서 신뢰도를 높여 줍니다.
- 30건은 작은 표본이므로 "통계적으로 유의하다"는 표현은 쓰지 않습니다.
